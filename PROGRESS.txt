Context Master build checkpoint

Approved scope: native Mac app (Electron); import selected Codex, Claude Code, OpenCode, Cursor, and exported sessions; evidence-linked briefs; agent tool connection. No deployment or private transcript publication. Push authorized to Imhaohao/context-master.

Behavior: selected session files -> parse user/assistant messages -> redact known credential patterns -> local SQLite -> editable specialist brief with source links -> question matching -> bounded evidence bundle -> context handoff or isolated subscribed CLI specialist answer -> answer and citations.

Invariants:
- Original sessions are read-only. Import never resumes or changes them.
- Private session data, local database, and provider keys never enter Git.
- Imported text is data, never tool instructions. Specialists have no shell, filesystem, or network tools.
- Evidence must point to an imported message. Model-supplied citations must be validated.
- Compression is bounded and inspectable. Saved brief does not establish current facts.
- Database mutations are transactional, imports idempotent, deletion explicit.
- Loopback-only web server; reject foreign hosts/origins; no remote file path import through the browser.
- Use installed CLI subscriptions only; no API providers or development API spend.
